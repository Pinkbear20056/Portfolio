# YUJIN. DEV. STUDIO

설치나 빌드가 필요 없는 HTML + CSS + JavaScript 정적 웹사이트입니다.

## 실행

압축을 먼저 풀고 `index.html`을 브라우저로 열어 주세요. 인터넷 연결 없이도 동작합니다.

- 메인: `index.html#home`
- 프로젝트: `index.html#projects`
- 경험: `index.html#experience`

## 파일

- `index.html`: 문서와 설명 팝업
- `styles.css`: 공통 디자인과 모바일 레이아웃
- `content.js`: 소개, 연락처, 사물 설명, 프로젝트와 경험 데이터
- `app.js`: 공통 템플릿, 페이지 이동, 사물 팝업, 앨범 선택
- `assets/`: 보내주신 참고 이미지 원본 사본

## 내용 수정

`content.js`에서 `introduction`, `location`, `email`을 수정하세요. 이메일이 비어 있으면 CONTACT에 준비 중 메시지를 표시합니다. 프로젝트·경험 문구와 기간은 예시이며 실제 이력으로 교체해야 합니다.

`projects`와 `experiences` 배열에 항목을 추가하면 자동으로 표시됩니다. `image`에는 기본 이미지 키인 `lens`, `shell`, `fabric` 또는 `assets/my-photo.jpg` 같은 사진 경로를 사용할 수 있습니다. 앨범 사진을 클릭하면 해당 사진 위에 `caption`이 나타나고 오른쪽 경험 항목이 강조됩니다.

## 이미지 구현 방식

메인 페이지는 collection.png 원본 사본에서 SVG 윤곽으로 잘라 표시한 트레이·조개·향수와 각각 배경을 분리한 camera.png, strap.png, keyring.jpg를 조합합니다. 악보는 제공된 winter wind.jpeg 원본을 사용하며 CSS 필터로 색감만 조절합니다. 타이틀은 실제 HTML인 ME.입니다. 프로젝트·경험 페이지의 사진은 기존 참고 시안 영역을 사용합니다.

이미지와 유사한 시스템 글꼴을 사용하므로 원본의 정확한 폰트와는 차이가 있을 수 있습니다. 모바일에서는 읽기 쉽도록 세로 레이아웃으로 전환합니다.

메인 사물 배치는 `app.js`의 `renderObjects()`에서 [x, y, 너비, 높이, 회전각]으로 조절합니다. 기준 캔버스는 1000 × 690입니다. `assets/objects.js`에는 각 이미지의 표시 영역과 클릭 윤곽이 들어 있습니다. 카메라·스트랩·키링은 알파 채널, 조개·향수는 원본에서 측정한 윤곽을 사용하며 표시와 클릭에 같은 경로를 적용합니다. 사물의 투명 여백과 키링 고리 구멍은 클릭되지 않으며 Tab, Enter, Space 키로도 설명을 열 수 있습니다. 악보는 종이 전체가 클릭 영역입니다. 바구니는 장식 배경입니다.

카메라·스트랩·키링의 배경 분리는 내장 이미지 편집 도구를 사용했습니다. 미세한 질감이나 글자에는 원본과 차이가 있을 수 있습니다. collection 이미지는 체크 배경 제거 결과가 불완전하여 원본을 코드로 잘라 표시했습니다. 프롬프트와 에셋 목록은 `ASSETS.md`에 기록했습니다.

## 배포

폴더의 파일과 assets 폴더를 같은 구조로 정적 호스팅에 업로드하면 됩니다. 외부 패키지, API 키, 서버, 데이터베이스가 필요 없습니다.
